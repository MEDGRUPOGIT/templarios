## Sobre o Projeto

Repositório **GitHub** criado com o objetivo de ser um distribuível para os pacotes compilados do [templarios-monorepo](https://github.com/MEDGRUPOGIT/templarios-monorepo). Como não temos uma conta privada no [npm](https://www.npmjs.com/), esse repositório nos permite a instalação dos pacotes contidos no [templarios-monorepo](https://github.com/MEDGRUPOGIT/templarios-monorepo) como dependências nos projetos que os consumirão.
